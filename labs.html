Case Standard

How every lab
gets evaluated.

Each lab answers the same four questions: what happened, what evidence proves it, how should someone respond, and how does this become repeatable? Anything that cannot answer all four stays staged.

Phase 01

Scenario

Build a controlled situation with enough realism to produce meaningful telemetry, and state the assumptions up front.

Phase 02

Detection

Write the query logic, validate the signal, and document where the false-positive boundary actually sits.

Phase 03

Triage

Turn raw events into findings with clear severity and scope, and record the decision points along the way.

Phase 04

Response

Package the workflow — actions, notes, escalation criteria — so the same pattern can be repeated and improved.
