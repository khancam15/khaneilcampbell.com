File 01

Authentication log analysis

Log Analysis · Splunk Published
Splunk SPL Windows Logs

Simulates a credential-based brute-force attempt by ingesting Windows Security Event Logs into Splunk, building SPL detection queries, and producing a structured analyst response workflow with documented triage decisions and a measurable outcome.

Scenario
Repeated failed logons suggest credential-attack behaviour against Windows accounts.
Telemetry
Windows Security logs reviewed and normalised inside Splunk.
Evidence
80+ failed logon attempts identified within a defined time window.
Open the full case GitHub ↗
01

Ingest

Collect and normalise Windows authentication events so they can be queried consistently.

02

Detect

Write SPL to group failed logon volume by source host, account, and time window.

03

Triage

Review correlated events, tune thresholds, and separate genuine signal from routine noise.

04

Respond

Document the actions taken, the escalation logic, and reusable case notes.

File 03

Access control workflows

Identity & Access Staged
Active Directory MFA Least Privilege

Documents operational identity scenarios: role-based access review, MFA enforcement, account lifecycle governance, privileged access handling, and least-privilege enforcement in day-to-day support work.

Scenario
An access or recovery request needs validating before anyone approves it.
Telemetry
Directory attributes, group membership, MFA state, and request context.
Evidence Goal
Least privilege enforced and approvals that hold up under pressure.

02

03

04
