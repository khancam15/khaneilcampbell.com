Authentication log analysis

Windows Security Event Logs ingested into Splunk, SPL detection queries, and a structured analyst response with documented triage decisions and a measurable outcome.

Scenario
Repeated failed logons suggest credential-attack behavior against Windows accounts.
Telemetry
Windows Security logs reviewed and normalized inside Splunk.
Evidence
80+ failed logon attempts identified within a defined time window.
Workflow
Ingest, detect, triage, respond: each step produces what the next depends on.
