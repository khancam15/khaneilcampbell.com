How I build with AI

A repeatable process, with a person accountable at every gate.

The same six steps run through the work on this site. Choose a step to see what it involves and where the evidence is.

  1. 01Define

    A requirements document where every line is labelled verified, proposed or needing evidence, so nothing unapproved is treated as fact.

  2. 02Decide

    Framework, hosting and content choices are written down with the options compared, the choice made and what it costs.

  3. 03Build

    Claude drafts and writes code against the approved requirements. I set direction, review every change and decide what merges.

  4. 04Check

    Security and accessibility audits, link checks, unit tests, credential scanning and dependency audits run before anything merges.

  5. 05Approve

    Work moves through milestones, and each ends with an explicit approval: plan, design, foundation, content, launch.

  6. 06Ship

    Changes reach production through reviewed pull requests, so every release is recorded and can be rolled back.
